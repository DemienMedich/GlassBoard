# GlassBoard

Прозрачная доска поверх окон Windows, C++17 / Qt 6.8 Widgets.

Текущая версия — **1.0.3**. Установщик: `dist\GlassBoardSetup_1.0.3.exe`. Portable-пакет: `dist\GlassBoard-1.0.3\GlassBoard.exe`; DLL и plugins должны оставаться рядом с EXE.

GlassBoard добавлен в PharosHub как `glass-board`. Для появления плитки в семейном каталоге установите последнюю версию самого Хаба. Подключите общую папку PharosHub кнопкой облака, затем нажмите «Установить» у GlassBoard. Версия в manifest, EXE и установщике должна совпадать.

- Перемещение: тяните свободное место возле боковой панели или Alt + перетаскивание стекла.
- Размер: тяните любую грань или угол. Минимум 260 × 540 логических пикселей; заметки сохраняют координаты при изменении размера, обрезанная часть вернётся при увеличении.
- Маркер: кнопка ✎ или B; цвет ● и слайдер размера 1–50 px. Для маркера и губки размеры запоминаются отдельно.
- Губка: ▱ или E, стирает только рисунок.
- Отмена: Ctrl+Z; повтор: Ctrl+Shift+Z.
- Снимок: ▧ или Ctrl+S. Снимок сразу копируется в буфер обмена (Ctrl+V), затем предлагается сохранение PNG. Отмена сохранения не удаляет снимок из буфера. PNG содержит экран под рабочей областью и заметки, без рамки и панели. Поддерживает несколько мониторов; защищённое от захвата содержимое может отсутствовать.
- Пропуск кликов: ⇢ или глобальная Ctrl+Alt+G. Возврат к рисованию: Ctrl+Alt+G даже из другой программы. Если сочетание занято, режим отключён.
- Очистка: ⌫ с подтверждением. Выход: × или Alt+F4.

Положение, размер, цвет и толщина запоминаются. Рисунки хранятся до закрытия; перед выходом сохраните нужные заметки снимком. Стекло слегка тонировано; это прозрачность, без размытия фона.

Сборка: `./build.ps1`; переносимый пакет: `./package.ps1` (Qt и MSVC пути задаются параметрами).
Проверка: `./verify_package.ps1` — запуск без Qt в PATH и проверка рисования, губки, отмены, повтора, изменения размера и захвата окна.

Настоящий установщик: `installer/build-installer.ps1` (или `-SkipPackage` для уже собранного пакета). Постоянный AppId сохраняет возможность обновления поверх предыдущей версии. Установка выполняется для текущего пользователя без администратора; удаление не стирает настройки QSettings `Faros/GlassBoard`.

Проверки используют отдельный `--data-dir` и `--smoke-output`, не записывают результаты в пакет и не меняют обычный профиль. Публикация: `publish-hub.ps1 -LifecycleReport <report.json>` после install/upgrade/uninstall. Правила дальнейших релизов: `AGENTS.md`. Отчёт релиза: `RELEASE_1.0.3.md`. История интеграции с Хабом: `HUB_RELEASE_1.0.2.md`.
